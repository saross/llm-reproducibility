- **(a) Adopted, option 2:** ranked evidence tiers for PAPER_ERROR.
  1. The paper's own tabulated data.
  2. The authors' deposited data for that analysis.
  3. The authors' own code, run **unmodified**, on their own data.

  The reproduction's own re-implementation never counts as evidence. The
  comparison report names the tier used, and human confirmation stays
  mandatory.
- **(b) Adopted:** the counting unit is the distinct datasets the paper's
  verification targets need as inputs.
  - Replicate runs presented as one result count as one dataset, available
    only if every part is retrievable.
  - Upstream sources count only when a target needs them; otherwise they
    are provenance (mirroring AP-10).
  - Dye stays L6 (1 of 2).
- **(c) Adopted:** each target's verification method states its scope,
  which must equal the target's full published scope. A partial check is
  completed, or the target counts against coverage as partially verified.
  Where feasible, the plan declares the target's element count, and a
  deterministic gate compares it with the elements checked.
- **(d) Adopted:** the bright line above, as a corollary of invariant 2,
  with two edge decisions.
  - **"Public"** means a release from the package's official archive (for
    example CRAN or PyPI) or a tagged public repository. Prefer the version
    current at publication.
  - **Repairs:** a repaired result is recorded as uplift evidence and never
    counts toward coverage or the verdict.
  - **Deprecated names:** first pin a public version that still runs the
    original name, which is routine. If none exists, replacing the name
    edits the authors' code, so it is fail-and-uplift, with no exception.
    This aligns with the position, Marwick among others, that capturing a
    working environment is the authors' responsibility.
